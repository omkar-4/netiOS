Page Tables (Mixed-Size Virtual Memory Management)
|-- CR3 Register (Page Directory Base Register)
| |-- Reserved (Bits 0-2)
| |-- PWT (Page-Level Write-Through) (Bit 3)
| |-- PCD (Page-Level Cache Disable) (Bit 4)
| |-- Reserved (Bits 5-11)
| |-- Physical Base Address of Level 4 Table (Bits 12-51: Must be strictly 4096-byte aligned)
| |-- Reserved (Bits 52-63)
|-- Paging Structure Hierarchy (4-Level Architecture)
| |-- PML4 (Page Map Level 4)
| | |-- Array of 512 u64 Entries (Size: 4096 Bytes, Alignment: #[repr(align(4096))])
| | |-- Scope: Maps 512 GB of Virtual Memory per entry
| |-- PDPT (Page Directory Pointer Table / Level 3)
| | |-- Array of 512 u64 Entries (Size: 4096 Bytes, Alignment: #[repr(align(4096))])
| | |-- Scope: Maps 1 GB of Virtual Memory per entry
| |-- PD (Page Directory / Level 2)
| | |-- Array of 512 u64 Entries (Size: 4096 Bytes, Alignment: #[repr(align(4096))])
| | |-- Branch A: Standard Entry (Bit 7 = 0) -> Pointers to Level 1 Page Tables
| | |-- Branch B: Huge Page Entry (Bit 7 = 1) -> Direct map to 2MiB Physical Framebuffer Blocks
| |-- PT (Page Table / Level 1)
| | |-- Array of 512 u64 Entries (Size: 4096 Bytes, Alignment: #[repr(align(4096))])
| | |-- Scope: Direct map to terminal 4KB Physical Frames (Standard RAM / LAPIC MMIO)
|-- Table Entry Atomic Layout (64 bits per entry)
| |-- Control Flags (Bits 0-11)
| | |-- P (Present): Bit 0 (1 = Hardware MMU will map, 0 = Trigger #PF Page Fault)
| | |-- RW (Read/Write): Bit 1 (1 = Writable, 0 = Read-only)
| | |-- US (User/Supervisor): Bit 2 (1 = Ring 3 User access allowed, 0 = Ring 0 Kernel only)
| | |-- PWT (Page-Level Write-Through): Bit 3 (1 = Enforced for LAPIC MMIO memory)
| | |-- PCD (Page-Level Cache Disable): Bit 4 (1 = Strict cache bypass for LAPIC MMIO)
| | |-- A (Accessed): Bit 5 (Hardware flips to 1 upon memory access)
| | |-- D (Dirty): Bit 6 (Hardware flips to 1 upon write; Valid in PT or Huge PD only)
| | |-- PS (Page Size): Bit 7 (1 = Terminate walk at PD for 2MiB Framebuffer pages, 0 = Next table)
| | |-- G (Global): Bit 8 (1 = Persist translation across CR3 context switches)
| | |-- OS-Available: Bits 9-11 (Free for software logic, unread by hardware)
| |-- Physical Base Address (Bits 12-51)
| | |-- Requires Mask: 0x000FFFFF_FFFFF000 to strip flags/high bits
| | |-- Target (Standard): Physical address of the next nested table
| | |-- Target (Terminal 4KB): Physical address of the 4KB RAM/MMIO block
| | |-- Target (Terminal 2MB): Physical address of the 2MB Framebuffer block
| |-- Reserved/Ignored (Bits 52-62)
| |-- NX/XD (No-Execute) (Bit 63)
| | |-- 1 = Instruction fetching strictly forbidden (Set for Framebuffer and Data memory)
|-- Address Translation & Indexing Math (Virtual to Physical)
| |-- Virtual Address Layout (48-bit canonical)
| | |-- Sign Extension (Bits 48-63): Must mathematically mirror Bit 47 (all 0s or all 1s)
| | |-- PML4 Index (Bits 39-47): Computed via (vaddr >> 39) & 0x1FF
| | |-- PDPT Index (Bits 30-38): Computed via (vaddr >> 30) & 0x1FF
| | |-- PD Index (Bits 21-29): Computed via (vaddr >> 21) & 0x1FF
| | |-- PT Index (Bits 12-20): Computed via (vaddr >> 12) & 0x1FF (Skipped for Framebuffer)
| | |-- Frame Offset (Bits 0-11): Computed via vaddr & 0xFFF (Bits 0-20 for 2MiB Huge Pages)
|-- TLB (Translation Lookaside Buffer) State Control
| |-- INVLPG Instruction (asm!("invlpg [{}]"))
| | |-- Purges a single specific virtual address (4KiB or 2MiB) from hardware cache
| |-- CR3 Hot-Swap (asm!("mov cr3, {}"))
| | |-- Purges all non-global cached page mappings instantly
