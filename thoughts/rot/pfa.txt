Physical Frame Allocator
|-- Source of Truth (Memory Map from Bootloader)
|   |-- Limine Memory Map Response
|   |   |-- Entries Array
|   |   |   |-- Base Address (64-bit physical address)
|   |   |   |-- Length (64-bit size in bytes)
|   |   |   |-- Type (Usable, Reserved, ACPI Reclaimable, Kernel/Modules, Bootloader Reclaimable)
|-- Initialization Phase (Bootstrapping the Allocator)
|   |-- Determine Total System RAM
|   |   |-- Sum of lengths of all "Usable" and "Bootloader Reclaimable" regions
|   |-- Calculate Required Bitmap Size
|   |   |-- (Total RAM / 4096) / 8 = Bytes needed for the tracking bitmap
|   |-- Find Placement for the Bitmap
|   |   |-- Scan memory map for the first "Usable" region large enough to hold the bitmap itself
|   |   |-- Claim this region (mark its bits as used) so the allocator doesn't overwrite its own ledger
|-- Tracking Data Structure (The Ledger)
|   |-- The Global Bitmap
|   |   |-- Byte Array (e.g., `&mut [u8]`) mapped to physical memory
|   |   |-- Bit Layout: 1 Bit = 1 Physical Frame (4096 bytes / 4KB)
|   |   |   |-- 0 = Free Frame
|   |   |   |-- 1 = Used / Reserved Frame
|   |-- Free Frame Cache (Optimization)
|   |   |-- Last Known Free Index (Caches the index of the last allocated frame to avoid scanning from 0 every time)
|   |   |-- Total Free Frames Counter (Tracks out-of-memory state instantly)
|-- Allocation Logic (`alloc_frame`)
|   |-- Search Phase
|   |   |-- Start at `Last Known Free Index`
|   |   |-- Iterate through bytes in the bitmap
|   |   |-- If byte != 0xFF (means at least one bit is 0)
|   |   |   |-- Scan bits 0-7 to find the exact free bit
|   |-- Claim Phase
|   |   |-- Set the specific bit to 1
|   |   |-- Update `Last Known Free Index`
|   |   |-- Decrement `Total Free Frames Counter`
|   |-- Return Phase
|   |   |-- Math: Physical Address = (Byte Index * 8 + Bit Index) * 4096
|-- Deallocation Logic (`free_frame`)
|   |-- Validation Phase
|   |   |-- Assert physical address is 4KB aligned (Address % 4096 == 0)
|   |-- Release Phase
|   |   |-- Math: Global Bit Index = Address / 4096
|   |   |-- Math: Byte Index = Global Bit Index / 8
|   |   |-- Math: Bit Offset = Global Bit Index % 8
|   |   |-- Clear the specific bit to 0
|   |   |-- Increment `Total Free Frames Counter`
|   |   |-- Update `Last Known Free Index` if released frame is lower than current cache
|-- Memory Locking / Initialization Sanity Rules
|   |-- Pre-mark Hardware Reserved: Iterate over Limine map, set all non-Usable regions to 1 in the bitmap
|   |-- Pre-mark Kernel Image: Ensure the physical addresses where Limine loaded your kernel ELF are set to 1
|   |-- Null Frame Protection: Explicitly mark Frame 0 (Physical Address 0x0) as used to trap null pointer dereferences
